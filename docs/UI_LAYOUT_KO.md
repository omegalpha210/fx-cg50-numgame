# 설정 화면·문구 배치·2048 색상 수정

이 문서는 과거 UI 수정 당시의 검증 기록이다. 현재 단일 RESUME과 START GAME,
펑션키 배치는 [최신 조작법](CONTROLS.md)을 따른다.

DIFF EQ와 같은 기본 글꼴과 30종 아이콘을 유지하면서, 실제 글자 폭을 기준으로
칸·정보 영역·결과창 안에 문구가 들어가도록 정리했다. 긴 숫자는 배율을 줄이고,
필요하면 작은 글꼴을 사용한다. 규칙·안내·결과 문구는 단어 단위로 줄바꿈한다.
최대 자릿수 통계·점수·타일, 긴 모드명·결과·수식 입력을 별도로 확인했다.
HARD Calcudoku의 `360*`처럼 긴 곱셈 단서는 곱셈 기호를 작게 그려 테두리와
겹치지 않게 했다. 숫자나 단서의 의미는 유지한다.

게임 진입 화면에는 저장된 게임이 있을 때의 RESUME, NEW GAME, 실제 필요한
설정만 표시한다. 단일 모드 게임의 MODE와 2048의 난이도·모드를 숨겼다.
Make Fifteen의 LOCAL 2P에서는 적용할 CPU가 없으므로 CPU LEVEL도 숨긴다.
다른 전략 게임의 난이도는 보드 크기·초기 숫자에도 영향을 주므로 유지한다.

위아래로 항목을 고르고 좌우로 설정을 바꾼다. 아래에는 선택한 항목의 간단한
설명을 표시한다. 펑션키는 **F4 STATS / F5 RULES / F6 OPEN**만 남겼으며,
EXE/F6은 현재 선택한 항목을 실행한다. 숫자 바로가기도 보이는 행 번호와 일치한다.
되돌릴 기록이 없을 때 UNDO, 확인창·일시정지창의 사용할 수 없는 버튼도 숨긴다.

2048의 타일과 메뉴 아이콘은 같은 색상표를 사용한다.

| 숫자 | 색상 |
|---|---|
| 2 | 회색 |
| 4 | 연두 |
| 8 | 시안 |
| 16 | 파랑 |
| 32 | 노랑 |
| 64 | 주황 |
| 128 | 마젠타 |
| 256 | 빨강 |
| 512–32768 | 단계마다 더 짙은 빨강 |
| 65536 이상 | 가장 짙은 빨강 유지 |

어두운 타일에는 흰 숫자를 쓴다. 큰 수는 칸에 맞춰 표시하며, 6자리 이상은
정확한 `2^지수` 표기를 사용한다. 점수·최대 타일 정보는 전체 숫자로 유지한다.

변경 범위는 표시와 진입 메뉴·기록 필터의 키 처리다. 게임 규칙·정답 판정·
2048 합치기·점수·난수·CPU·저장 형식·타이머는 수정하지 않았다. 두 게임 소스의
변경도 렌더링 함수 내부에만 있다. 재개 시 저장된 게임 전체가 유지됨을 확인했다.

위 수치와 범위는 당시 UI 변경의 역사적 검증이다. 현재 MASTER/HELL 확장까지의
통합 검사는 `bash tools/test.sh`와 `tests/test_ui_layout.c`를 실행하고
[현재 검증 범위](ACCEPTANCE.md), [콘텐츠 감사](CONTENT_INVENTORY.md),
[측정 방법](MEMORY_METHOD.md)을 참고한다. 최신 renderer 화면은
[캡처 목록](captures/README.md)에서 확인할 수 있다.
실제 계산기 LCD 확인과 기존 ASan 런타임 미검증은 그대로 남아 있다.
