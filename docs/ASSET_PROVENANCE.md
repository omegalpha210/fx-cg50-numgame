# Asset and source provenance

Original NUM GAME assets:

- `assets/icon-uns.png` and `icon-sel.png`: native92×64 number/operator tile
  geometry generated by `tools/make_assets.py`, with rows42–63 reserved for the
  OS's own NUM GAME label. No imported artwork, logos or screenshot background.
- `assets/guesscalc_packs.json` and matching C header:900 original generated
  records, deterministic generator and independent verifier under `tools/generate`.
- `assets/grids/11.json`…`20.json` and `src/games/grids_pack.c`:810 original
  uniqueness-verified puzzles plus90 explicitly distinguished Magic layouts.
- `assets/strategyquick/tables.h`:6,382 bytes of original bounded game analysis;
  no externally copied AI table or puzzle instance.
- `docs/captures`: actual shared native-renderer output through a host RGB565
  backend, plus nearest-neighbor contact sheets. Original Sudoku note geometry
  is defined in the grid renderer. Captures are not physical device photographs.
- `src/ui/icons.c`: 30 original game pictograms and one statistics pictogram,
  authored as native 40×32 line/rectangle geometry. No external icon pack,
  artwork or game state is used. Category tiles reuse representative pictograms.

- `src/ui/tiles.c`: original RGB565 2048 palette shared by board and menu icon,
  ordered gray/lime/cyan/blue/yellow/orange/magenta/red with darker high tiles.

Font:

- `assets/font/font5x7.png` and `font8x9.png` are copied from the installed gint source at revision
  `badbd0fd2bd8ac796fd55d49b93691741bd8a139`. The generated `src/ui/font_data.h`
  preserves the glyphs and is covered by gint's permissive README
  statement, retained in `docs/third_party/gint-README.md`. Atlas padding is
  decoded explicitly; no proprietary CASIO ROM font is copied.
- Normal text now uses native gint 8×9, with 11 raster rows and proportional
  advances, matching DIFF EQ's `tests/host/font_data.h` byte-for-byte. The 8×9
  atlas is SHA256 `0e7f56f30e021e16053360b972adc0b020c7d8a2d545fbd883bc8e7d870413c8`,
  identical to DIFF EQ's attributed vendor copy. Compact clues retain 5×7.

- Read-only SOKOBAN reference revision
  `4287f21df24e4d7abea06eb17a849bbbb4cb862b`: MENU/OFF and key-release patterns,

- Read-only DIFF EQ reference revision

The authored bounded domains, operators and local options are documented in
the in-app registry and exported [RULES.md](RULES.md).

`asset-manifest.json` records SHA256/size for licensed font data, original icons,
JSON packs and native tables/sources. `tools/check_embedded.py` regenerates
embedded text and policy bytes in an isolated temporary directory and checks
they match verified source metadata. Test-only witnesses never become automatic
answer acceptance rules.

`THIRD_PARTY_NOTICES.md` links complete notices for adapted infrastructure,
font/runtime, C library, compiler runtime and SDK. No unlicensed Sokoban maps or
other commercial puzzle-pack content is included. Machine-specific ASan process samples are private development evidence and
are excluded from the public snapshot. ASan remains NOT VERIFIED; the minimal
host runtime stalls before main. Supplemental renderer captures are not runtime assets.

## Runtime/BOARD follow-up assets

GUESS/Baseball code tiles, Shikaku rectangles and Slitherlink loop icons are
original compact geometry in src/ui/icons.c. No fetched sports icon or bitmap
cache is used. New board and MASTER JSON/C problem packs were generated locally;
independent counters/ratings are retained with their generators and audits.
Nikoli's public [Shikaku rules](https://www.nikoli.co.jp/en/puzzles/shikaku/) and
[Slitherlink rules](https://www.nikoli.co.jp/en/puzzles/slitherlink/) informed the
rule descriptions only. Their sample puzzle diagrams/assets were not copied.

The current before/after puzzle counts, all new MASTER/HELL sources and per-asset
hashes are maintained in [CONTENT_INVENTORY.md](CONTENT_INVENTORY.md); the quantities
above describe the original pack baseline, not the final expanded total.
