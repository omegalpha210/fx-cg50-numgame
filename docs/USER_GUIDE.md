# NUM GAME 사용 안내 (beta.6)

NUM GAME은 fx-CG50용 숫자 게임 36종을 담은 네이티브 애드인입니다.
`dist/NUMGAME.g3a`를 계산기의 USB 저장소에 복사하고 안전하게 연결을 해제한 뒤
메뉴에서 **NUM GAME**을 여세요. 문제 파일을 따로 복사할 필요는 없습니다.
`dist/NUMGDIAG.g3a`는 기기 진단을 위한 별도 앱이며 진행 파일도 따로 씁니다.

메인 화면에서 방향키로 분류를 고르고 EXE로 여세요. 각 분류에는 게임 여섯 개가
있습니다. 숫자 1–6으로 타일을 바로 선택할 수도 있습니다. 게임을 열면
UP/DOWN으로 NEW GAME, 난이도, 필요한 설정 행을 고르고 LEFT/RIGHT로 값을
바꿉니다. 현재 행의 설명은 화면 아래에 표시됩니다. F5 RULES는 실제 게임
규칙을 보여주고, EXE 또는 F6 OPEN은 선택한 항목에 따라 새 게임을 시작하거나
저장한 게임을 엽니다. LOGIC 게임의 HELL은 난이도 행에서 F3로 선택합니다.

앱 전체에서 미완료 게임 **하나**만 이어할 수 있습니다. 그 게임의 타일에는
RESUME 표시가 붙고 메인 F1에서도 바로 엽니다. 같은 게임의 시작 화면에는
RESUME 행이 NEW GAME 위에 나타납니다. **RESUME**은 문제, 입력, 진행 상황과
출제 순서를 그대로 복원합니다. **NEW GAME**은 현재 설정의 다음 문제를
선택하고, 기존 이어하기를 새 판으로 교체합니다. INIT은 *같은 문제*를 다시
시작합니다. 게임을 마치면 이어하기가 지워지지만 결과 창에서 EXIT으로 최종
화면을 볼 수 있고 F6 NEW로 같은 설정의 다음 판을 시작할 수 있습니다.

MAKE TARGET의 TARGET 행은 **10 → 24 → 50 → 100 → 200 → RANDOM** 순서이며
끝에서 더 이동하지 않습니다. 고정 목표에는 난이도마다 200개의 검증된 카드
문제가 있습니다. RANDOM은 난이도를 유지하면서 다섯 목표의 1,000문제 중
목표와 카드 묶음을 함께 고릅니다. 실제로 맞춰야 할 숫자는 플레이 화면에
나옵니다. 모든 카드를 정확히 한 번 써야 하고 EASY/NORMAL/HARD/MASTER에서
카드는 각각 4/4/5/6장입니다. 예전 임의 목표로 저장한 미완료 판은 그대로
이어할 수 있습니다. 그 목표가 새 선택지에 없으면 판을 마친 뒤 다음 NEW에서
TARGET을 직접 다시 고르게 됩니다.

COUNTDOWN은 목표에 닿으면 되지만 카드 여섯 장을 모두 쓸 필요는 없습니다.
각 카드는 최대 한 번, 중간값은 양의 정수, 나눗셈은 정확히 나누어떨어질 때만
허용됩니다. 난이도마다 200문제를 제공합니다. PRIME FACTOR는 합성수를
소인수로 나눕니다. EASY는 3자리, NORMAL은 3·4자리, HARD는 4·5자리,
MASTER는 5·6자리입니다. 자릿수뿐 아니라 소인수 구조도 난이도에 반영됩니다.

NUMBER BASEBALL은 반복되는 숫자와 맨 앞의 0을 허용합니다. 난이도 순으로
4/5/6/7자리이고, 마지막 기회까지 포함한 총 시도 횟수는 20/30/40/50회입니다.
끝에서 두 번째 시도가 틀리면 ONE LAST TRY가 한 번 뜹니다. EXE나 EXIT으로
닫아도 시도 횟수는 줄지 않습니다. **S**는 숫자와 자리가 모두 맞은 개수,
**B**는 숫자는 맞고 자리는 다른 개수입니다. UP/DOWN으로 이전 추측을
스크롤할 수 있으며 입력 중인 숫자는 그대로 남습니다. EQUATION GUESS와
NUMBER MIND의 긴 기록·단서 목록도 같은 방식으로 스크롤합니다.

`NGSTATEA.dat`와 `NGSTATEB.dat`는 하나의 진행 상태를 위한 복구 사본 두
개입니다. 정상적인 이어하기가 있다면 두 파일을 임의로 지우지 마세요.
실기에서 저장 시간이 얼마나 걸리는지, 화면의 글자가 얼마나 선명한지,
이전에 보고된 MENU 깜빡임이 재현되는지는 아직 확인이 필요합니다.

게임마다 다른 키는 [전체 조작표](CONTROLS.md)와 화면의
[RULES](RULES.md)를 참고하세요. [현재 설정별 문제 수](CONTENT_INVENTORY.md),
[출제 순환](CONTENT_CYCLE.md), [저장 형식](STORAGE_FORMAT.md),
[실기 확인 항목](HARDWARE_RETEST.md)도 공개되어 있습니다.
